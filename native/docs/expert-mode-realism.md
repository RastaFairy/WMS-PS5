# Expert mode: machine and LOGI PRO references

The in-game HS-6008 machine texture is a generated transparent product-style recreation based on the product reference supplied by the user: https://www.gacommercial.co.uk/cdn/shop/products/151_HS-6008-logipro-front-a_2048x2048.jpg. It is not a copied manufacturer photograph.

Mission details use the supplied LOGI PRO operating manual for HS-6008/RMS610/RMG, general application: P-1 Extra Heavy Soil = 66 min/8 phases, P-2 Heavy Soil–White = 56 min/7 phases, P-7 Synthetics = 30 min/5 phases, P-8 Delicates and Wool = 31 min/5 phases. The manual identifies LOGI PRO compartments 1 (powder), 2 (powder), 3 (liquid bleach), and 4 (liquid softener/neutraliser), and recommends nominal cotton loads, 80–90% nominal for synthetics, and 35–50% nominal for delicate fabrics. The simulator simplifies the actual phase vectors. Its 800/600 rpm limits are explicitly game-only rules, not manufacturer-specified rpm values.

Gameplay note: the drawer remains a simplified interactive model of compartments I, II and F; compartment III (liquid bleach) is documented by the manual but is not yet simulated as a separate selectable dose. Expert program names map the game's first eight selector positions to LOGI PRO P-1..P-8 in the first four expert missions; mission five uses the standalone Spin action. The 80 °C option remains selectable because it appears in the P-1 phase table, but the game blocks a wash above the strictest care label in the selected load. The current P-1 mission load is therefore set to 30 °C. The EH020 parts handbook confirms shared HS-6008/EH020 mechanical views and model-specific parts; this project depicts the HS-6008 variant and does not claim identical electrical/regional configurations.
